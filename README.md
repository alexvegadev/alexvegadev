## Selected projects

### [OSCAR — AI orchestration runtime](https://github.com/alexvegadev/oscar_agent)

An experimental, local-first runtime written in Rust for planning tasks, routing work across local and remote models, and inspecting execution.

- Bounded execution, validation hooks, and usage reporting.
- Opt-in RAG over explicitly loaded files, using local embeddings.
- Opt-in MCP tool registration with explicit capability boundaries.

**Status:** Experimental. See the repository for implemented features and current limitations.

### [Go Clean Architecture Template](https://github.com/alexvegadev/go-clean-arch-template)

A Go backend template organized around package-oriented design, using Gin, Viper, and MySQL, with Prometheus, Alertmanager, and Logrus for monitoring, alerting, and logging.

**Focus:** Backend structure · Configuration · Operational visibility
